---

## 💻 Sobre o Projeto

O **Alura Books** é uma plataforma focada em navegação e busca de livros. O objetivo principal do projeto é aplicar conceitos essenciais do ecossistema React, como componentização, modularização do CSS com *styled-components* e gerenciamento de estado da aplicação.

---

## 🎨 Funcionalidades

- [x] **Header Institucional:** Navegação com links para Categorias, Favoritos e Minha Estante.
- [x] **Barra de Pesquisa:** Componente interativo para busca de títulos.
- [x] **Estilização Modular:** Layout construído com `styled-components`.
- [ ] **Carrossel de Livros:** Exibição dos lançamentos e mais vendidos.
- [ ] **Integração com API:** Consulta dinâmica de catálogo de livros.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://reactjs.org/)** — Biblioteca principal para construção da interface.
- **[Styled-Components](https://styled-components.com/)** — Estilização via CSS-in-JS.
- **JavaScript (ES6+)** — Lógica e manipulação de dados.

---

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter instalado em sua máquina o [Git](https://git-scm.com) e o [Node.js](https://nodejs.org/pt-br/).

### Passo a passo

```bash
# 1. Clone este repositório
$ git clone [https://github.com/kaynanvieira/alura-books.git](https://github.com/kaynanvieira/alura-books.git)

# 2. Acesse a pasta do projeto
$ cd alura-books

# 3. Instale as dependências
$ npm install

# 4. Execute a aplicação em modo de desenvolvimento
$ npm start
